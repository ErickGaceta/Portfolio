Case Study

Learning Journal System

OJT internal training system for structured documentation and training record management.

Problem

Trainers manually filled out Word templates, printed documents, signed them, and submitted physical copies for record-keeping. This process was slow, inconsistent, and difficult to manage at scale.

Objective

To digitize training documentation by centralizing training records, standardizing outputs, and enabling structured submission of employee training logs.

System Roles

Admin (MIS)

Manages system oversight and user administration.

HR / Secretary

Encodes training schedules and manages training data.

Employee

Submits training documentation outputs per assigned activity.

Data Model (Simplified)

  • Roles Table – Defines system access levels
  • Training Table – Stores training schedules and activity details
  • Document Table – Stores employee-submitted outputs
  • Users Table – Handles authentication and role mapping

Workflow

HR encodes training schedules
→
Employees access assigned training
→
Employees submit documentation
→
Admin reviews and manages records

Key Contribution

Replaced a manual Word-based documentation workflow with a structured digital system, improving consistency, accessibility, and centralized record management.

Development Context

Built under OJT constraints without formal SDLC documentation, focusing on functional implementation and role-based workflow correctness.
